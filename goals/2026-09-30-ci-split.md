The browser lane is 28 of main's 34 minutes (37 on the last PR) because 48 guards run one after another, each starting its own vite preview. Split it out of Build & test into parallel jobs so a PR is green in about 15 minutes, with every guard still required.

## Shape

- Build & test keeps its name (the ruleset requires it) and keeps everything that is not a browser guard: install, build, lint, unit and persistence tests, the diff guards.
- Two new jobs, Browser guards A and Browser guards B, each: checkout, install, build once, one vite preview per shard, ports recorded in the shard file, run its half of the 48 guards against it with CAPTURE_BASE_URL exported, upload each guard's log as an artifact on failure. timeout-minutes 25 each.
- Shard by measured duration, not by name: read the step times from main's last green run and balance A and B to within two minutes. Keep the shard lists in one file, .github/browser-shards.json, with the measured seconds beside each guard so the next rebalance is a data edit.
- Any guard that says "against this build" or needs its own flags or its own server keeps its own step inside its shard; say which and why in the PR.
- Build & test no longer starts a preview server at all. If any non-browser step secretly needed one, it moves to a shard.

## Ruleset

The new jobs must become required checks before the first PR of this goal merges, or a red shard could not block a merge. Print the exact job names for me to add in GitHub, then stop until I say they are in. Sequence: open the PR, CI shows the new jobs, I add them as required, then the merge line.

## Tooling that reads check names

npm run pr:merge and the five-marks line list checks by name. Extend both: pr:green means Build & test, Browser guards A, Browser guards B, Vercel Preview Comments, and Vercel where present. Update WORKFLOW.md. npm run verify already excludes preview-server steps; make it read the shard file so a local "run shard A" is one command, and record in WORKFLOW.md that a local shard run is the pre-PR check for shared chrome.
